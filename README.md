# 🛵 Scooty Mileage Calculator

A beginner-friendly Python project to calculate scooty mileage and petrol expenses.

## ✨ Features
- Calculates petrol used in litres
- Calculates mileage (km per litre)
- Calculates petrol cost per kilometre
- Allows repeated calculations
- Checks for invalid inputs

## 🚀 How to Run
1. Download `petrol.py'
2. Open it in VS Code
3. Run the Python file
4. Enter petrol price, petrol amount and distance travelled
